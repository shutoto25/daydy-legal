プライバシーポリシー

最終更新日: 2026年8月8日

本アプリ「daydy」の運営者（以下「運営者」）は、本アプリにおける利用者の個人情報およびデータの取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 取得する情報

本アプリは、サービス提供のために以下の情報を取得します。

1.1 利用者が作成・提供する情報

情報内容取得の要否
ひとコマ（写真・動画）利用者が記録した写真・動画、およびそのサムネイル本アプリの中核機能に必須
位置情報写真・動画の EXIF に含まれる GPS 情報、およびそれを逆ジオコーディングして得られる地名任意（利用者が設定・クリア可能）

1.2 アカウント情報

  • 認証プロバイダ（Google）を通じて取得する識別子およびメールアドレス。
  • 本アプリはログイン必須です。認証は Firebase Authentication を利用します。

1.3 自動的に取得される情報

  • クラッシュ情報・利用状況: アプリの安定性向上のため、クラッシュレポートおよびアプリ起動回数等の統計情報を取得します（Firebase Crashlytics / Analytics）。日記の内容（写真・動画・地名）はこれらの分析データに含まれません。
  • プッシュ通知トークン: リマインド通知の配信のため、デバイスの FCM トークンを取得します。

2. 利用目的

  1. 本アプリの中核機能（ひとコマの記録・閲覧・リール生成・エクスポート）の提供
  2. 端末間でのデータ同期
  3. リマインド通知の配信
  4. 不具合の検知と品質改善
  5. 利用者からのお問い合わせ対応

3. 情報の保存と同期

  • ひとコマ（写真・動画・サムネイル）および関連メタデータは、まず端末内に保存されます（オフラインファースト）。
  • ログイン中は、これらのデータが運営者のサーバー（クラウドストレージを含む）へ同期・保存されます。これにより端末間での閲覧やリールのエクスポートが可能になります。
  • 通信はすべて暗号化（HTTPS/TLS）された経路で行われます。
  • 端末内のデータベースは暗号化して保存されます。

4. 第三者への提供・委託

運営者は、以下のサービス提供事業者に対し、サービス運営に必要な範囲で情報の取り扱いを委託します。これらの事業者は各社のプライバシーポリシーに従って情報を取り扱います。

事業者利用目的
Google LLC（Firebase）認証、クラッシュ解析、利用統計、プッシュ通知
Google LLC（Google Maps Platform）地名の逆ジオコーディング
Amazon Web Services, Inc.サーバー・ストレージの提供

上記のほか、法令に基づく開示義務がある場合を除き、利用者の同意なく個人情報を第三者に提供することはありません。

5. 位置情報の取り扱い

  • 本アプリは、写真・動画の EXIF に含まれる位置情報を利用します。継続的な位置追跡（バックグラウンドでの現在地取得）は行いません。
  • 地名の取得（逆ジオコーディング）のため、緯度・経度が第三者サービスに送信される場合があります。
  • 利用者は各ひとコマの位置情報を手動で設定・削除できます。

6. データの削除（削除される権利）

  • 利用者は、各ひとコマを個別に削除できます。
  • アカウント削除機能により、運営者が保持する利用者のデータ（データベース、メディア、キャッシュ、暗号化キー、ログ）の削除に対応します。

7. 子どものプライバシー

本アプリは 13 歳以上の利用を想定しています。13 歳未満の子どもから意図的に個人情報を取得することはありません。

8. 安全管理措置

通信経路の暗号化（TLS）、端末内データベースの暗号化、認証トークンによるアクセス制御など、適切な安全管理措置を講じます。

9. 本ポリシーの変更

本ポリシーは、法令の変更やサービス内容の変更に応じて改定されることがあります。重要な変更がある場合は、本アプリ内または運営者の公表する方法で通知します。
